# Calculadora 3DTop

Calculadora de custo, preço de venda e lucro bruto para peças impressas em 3D.

Acesse pelo celular: https://agmedig.github.io/calculadora-3dtop/

Para instalar como aplicativo:
- **Android (Chrome):** menu ⋮ → "Adicionar à tela inicial" ou "Instalar app".
- **iPhone (Safari):** Compartilhar → "Adicionar à Tela de Início".

Os valores digitados ficam salvos apenas no aparelho de quem usa.
